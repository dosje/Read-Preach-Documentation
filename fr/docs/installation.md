# Installation

Read & Preach est disponible pour **iPhone & iPad** et pour **Android**.

## Prérequis

| | iPhone & iPad | Android |
|---|---|---|
| Appareils | iPhone et iPad | Smartphones et tablettes |
| Système | iOS 18.2 ou version ultérieure | Android 8.0 ou version ultérieure |
| Store | App Store | Google Play |

Aucune connexion Internet requise après l'installation.

## iPhone & iPad

### Installation depuis l'App Store

1. Ouvrez l'[**App Store**](https://apps.apple.com/app/read-preach/id6760897523) sur votre iPhone ou iPad
2. Recherchez **"Read & Preach"**
3. Appuyez sur **Obtenir**, puis authentifiez-vous avec Face ID, Touch ID ou votre mot de passe Apple ID
4. L'application se télécharge et apparaît sur votre écran d'accueil

### Mettre à jour l'application

1. Ouvrez l'**App Store**
2. Appuyez sur votre icône de profil en haut à droite
3. Faites défiler vers le bas pour voir les mises à jour disponibles
4. Appuyez sur **Mettre à jour** à côté de Read & Preach

Vous pouvez également activer les mises à jour automatiques dans **Réglages → App Store → Mises à jour des apps**.

### Désinstallation

Appuyez longuement sur l'icône Read & Preach sur votre écran d'accueil → **Supprimer l'app** → **Supprimer l'app**.

## Android

### Installation depuis Google Play

1. Ouvrez [**Google Play**](https://play.google.com/store/apps) sur votre smartphone ou votre tablette
2. Recherchez **"Read & Preach"**
3. Appuyez sur **Installer**
4. L'application se télécharge et apparaît dans la liste de vos applications

### Mettre à jour l'application

1. Ouvrez **Google Play**
2. Appuyez sur votre icône de profil en haut à droite → **Gérer les applications et l'appareil**
3. Appuyez sur **Mises à jour disponibles**, puis sur **Mettre à jour** à côté de Read & Preach

Google Play met à jour les applications automatiquement par défaut.

### Désinstallation

Appuyez longuement sur l'icône Read & Preach → **Désinstaller** (ou faites-la glisser vers **Désinstaller**). Vous pouvez aussi passer par **Paramètres Android → Applications → Read & Preach → Désinstaller**.

## Transférer les données vers un nouvel appareil

Read & Preach stocke toutes les données localement. Pour transférer vos données :

1. Sur votre **ancien appareil** : ouvrez Read & Preach → **Paramètres → Export & Import** (sous Android : **Paramètres → Général → Export & Import**)
2. Appuyez sur **Exporter**, choisissez ce qui doit être inclus, et enregistrez le fichier (par ex. dans iCloud Drive, Fichiers, Google Drive ou par e-mail)
3. Sur votre **nouvel appareil** : installez Read & Preach
4. Ouvrez **Paramètres → Export & Import → Importer**
5. Sélectionnez votre fichier exporté — toutes les données seront restaurées

Le fichier d'export est identique sur les deux plateformes : vous pouvez donc aussi transférer vos données **de l'iPhone vers Android** et **d'Android vers l'iPhone**.

> **Important :** La désinstallation supprime définitivement toutes les données de votre appareil. Exportez vos données au préalable si vous souhaitez les conserver.
