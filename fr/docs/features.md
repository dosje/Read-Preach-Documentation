# Fonctionnalités

> Les fonctionnalités marquées *Disponible à partir de …* nécessitent cette version de l'application ou une version ultérieure. Mettez l'application à jour pour en profiter. Toutes les versions sont décrites dans [Nouveautés](../whats-new/).

## Onglet Rapport

L'onglet Rapport est votre journal de ministère quotidien.

### Saisie quotidienne

Pour chaque jour, vous pouvez enregistrer :
- **Heures** — temps réel passé dans le ministère
- **Heures planifiées** — temps prévu à l'avance
- **Placements** — littérature ou magazines partagés
- **Études bibliques** — études conduites
- **Commentaires** — notes personnelles

### Calendrier

Le calendrier affiche le mois en cours avec des indicateurs visuels sur les jours avec des données :
- Appuyez sur un jour pour basculer vers ce jour
- Glissez à gauche/droite pour naviguer entre les mois
- Appuyez sur le titre du mois pour accéder rapidement à n'importe quel mois
- Appuyez sur **Aujourd'hui** pour revenir à la date actuelle

Sur iPhone, le calendrier peut être réduit en vue hebdomadaire compacte. Sur iPad, il est toujours visible.

Sur les tablettes Android, l'onglet Rapport s'ouvre avec le calendrier du mois. En mode paysage, un rail de navigation latéral remplace la barre d'onglets du bas ; vous pouvez le placer à gauche ou à droite dans **Paramètres → Général**.

### Récapitulatif mensuel

Sous le formulaire quotidien, une carte de synthèse affiche :
- Total des heures ce mois-ci par rapport à l'objectif mensuel
- Heures restantes pour atteindre l'objectif
- Placements et études bibliques pour le mois
- Totaux annuels et objectif annuel

### Gestion des rôles

Sous **Paramètres → Paramètres de rapport** :
- **Rôle récurrent** — Proclamateur, Pionnier auxiliaire ou Pionnier régulier avec mois de début
- **Mission ponctuelle** — mois de pionnier auxiliaire temporaire (15 ou 30 heures)
- **Historique des rôles** — journal de tous les changements de rôles passés

### Crédit d'heures

*Disponible à partir d'iOS 1.6.0 · Android 1.1.0*

Les pionniers réguliers peuvent enregistrer des heures de crédit. Elles comptent pour l'objectif d'heures et sont affichées séparément des heures de ministère.

### Étudiants de la Bible

*Disponible à partir d'iOS 1.6.0 · Android 1.1.0*

Tenez une liste de vos étudiants de la Bible et cochez chaque jour ceux avec qui vous avez étudié. Chaque étudiant compte une fois par mois : le récapitulatif mensuel affiche donc le nombre de cours bibliques **différents** (appuyez dessus pour voir les noms). Ce nombre est aussi utilisé dans le rapport partagé, la vue de l'année de service et le PDF.

- Ajoutez un étudiant dans **Paramètres → Paramètres de rapport → Étudiants de la Bible**, ou directement dans le rapport du jour avec **+ Ajouter un étudiant de la Bible**
- Un étudiant que vous n'avez coché aucun jour peut être supprimé (avec confirmation). Les étudiants déjà utilisés dans vos rapports peuvent seulement être archivés, pour que les mois passés restent exacts *(iOS 1.7.0 · Android 1.1.1)*
- Sans étudiant actif, vous pouvez toujours compter vos cours bibliques avec le compteur ; un message vous rappelle qu'ajouter un étudiant permet de compter par nom

Les noms des étudiants restent sur votre appareil et dans votre fichier de sauvegarde. Ils n'apparaissent jamais dans un rapport partagé, dans le PDF ni dans un rapport envoyé à NW Publisher.

### Vue d'ensemble de l'année de service

*Disponible à partir d'iOS 1.5.0 · Android 1.0.0*

Appuyez sur **Voir l'année de service** en bas de la carte de récapitulatif mensuel.

- Utilisez le sélecteur en haut pour choisir n'importe quelle année de service (septembre–août) pour laquelle vous avez des données
- Le tableau affiche les 12 mois avec le rôle que vous aviez ce mois-là, vos heures, placements et études bibliques
- Les mois futurs sont affichés avec des tirets et grisés
- Une icône **!** orange apparaît à côté des mois passés où un objectif de pionnier n'a pas été atteint (Pionniers auxiliaires et missions ponctuelles uniquement — les Pionniers réguliers suivent l'année complète)
- La section objectif sous le tableau affiche :
  - **Pionnier auxiliaire / mission ponctuelle** — l'objectif mensuel pour ce mois
  - **Pionnier régulier** — le total annuel vs. l'objectif annuel de 600 heures
  - **Proclamateur** — aucune section objectif
- Appuyez sur le bouton partager (en haut à droite) pour exporter l'année en PDF et ouvrir la feuille de partage (enregistrer dans Fichiers ou Google Drive, imprimer ou partager via n'importe quelle application)

### Partager le rapport

*Disponible à partir d'iOS 1.5.0 · Android 1.0.0*

Appuyez sur **Partager le rapport** en bas de la carte de récapitulatif mensuel pour envoyer votre rapport mensuel sous forme de message.

- Le message s'adapte à votre rôle :
  - **Pionnier ou mission ponctuelle** — inclut vos heures et études bibliques du mois
  - **Proclamateur (sans objectif)** — indique simplement « Ministère effectué : oui »
- La feuille de partage du système s'ouvre pour envoyer via Messages, WhatsApp, e-mail ou toute autre application

### Envoyer à NW Publisher

*Disponible à partir d'iOS 1.6.0 · Android 1.1.0*

Envoyez le rapport du mois précédent à l'application NW Publisher installée sur le même appareil :

1. Dans l'onglet Rapport, allez au mois précédent et appuyez sur **Envoyer à NW Publisher** dans le récapitulatif mensuel
2. Vérifiez les valeurs : **J'ai participé à la prédication ce mois-ci**, cours bibliques différents, heures entières (pionniers), crédit (pionniers réguliers) et une **remarque pour le secrétaire** facultative
3. S'il reste des minutes, vous pouvez les reporter au 1er du mois en cours
4. Appuyez sur **Ouvrir NW Publisher** : NW Publisher s'ouvre avec le formulaire de rapport rempli. Vérifiez les valeurs et appuyez sur **Envoyer**

Le rapport est transmis uniquement à l'application NW Publisher installée, jamais à un site web, et les noms des étudiants ne sont jamais envoyés. Si NW Publisher n'est pas installé, rien n'est envoyé.

**Bannière de rappel** *(iOS 1.7.0 · Android 1.1.1)*
Du 1er au 10 de chaque mois, l'onglet Rapport affiche une bannière telle que **« Rapport d'octobre · Envoyer à NW Publisher »** si le mois précédent contient des données. Appuyez dessus pour ouvrir la boîte de dialogue du mois précédent. La bannière disparaît dès que vous avez ouvert NW Publisher pour ce mois. Appuyez sur **✕** pour la masquer pour ce mois (vous pouvez annuler aussitôt), ou désactivez-la dans **Paramètres → Paramètres de rapport → Rappel NW Publisher**.

## Minuteur de ministère

*Disponible à partir d'iOS 1.3.3 · Android 1.0.0*

Le minuteur de ministère mesure la durée de votre activité de prédication et vous permet d'enregistrer ce temps directement dans votre rapport quotidien.

### Utilisation

Appuyez sur le bouton du minuteur dans l'onglet Rapport pour ouvrir le Minuteur de ministère :
- **Démarrer** — lance le chronométrage au début du service
- **Pause / Reprendre** — mettez le minuteur en pause lors des interruptions et reprenez ensuite
- **Arrêter** — termine la session ; une boîte de dialogue affiche votre temps arrondi aux 30 minutes les plus proches, prêt à être ajouté à l'entrée du jour

### Widgets d'écran d'accueil — iPhone & iPad

Ajoutez un widget Minuteur de ministère à votre écran d'accueil. Deux tailles sont disponibles :
- **Petit** — affiche le minuteur actuel avec des contrôles icône-only (Pause/Reprendre et Arrêt)
- **Moyen** — affiche le minuteur à gauche et des boutons étiquetés (Pause, Reprendre, Arrêt) à droite

Les deux tailles se mettent à jour automatiquement et permettent de contrôler le minuteur sans ouvrir l'application.

### Live Activity & Dynamic Island — iPhone

Lorsque vous démarrez le minuteur, une Live Activity est créée automatiquement sur les appareils compatibles :
- **Écran verrouillé** — affiche le temps écoulé avec les contrôles Pause/Reprendre et Arrêt
- **Dynamic Island** (iPhone 14 Pro et ultérieurs) — affiche un minuteur animé compact dans la pastille ; appui long pour développer et accéder aux contrôles

### Widget & notification — Android

- **Widget d'écran d'accueil** — affiche le temps écoulé avec un bouton Pause/Reprendre. Le widget est redimensionnable ; appuyez dessus pour ouvrir l'application.
- **Notification du minuteur** — tant que le minuteur tourne, une notification affiche le temps écoulé avec **Pause/Reprendre** et **Arrêter**. Arrêter ouvre l'application pour enregistrer le temps dans votre rapport.

## Onglet Bible

L'onglet Bible suit votre progression à travers les 1 189 chapitres de la Bible.

### Carte de progression

En haut de l'onglet Bible, la carte de progression affiche :
- Un indicateur de progression circulaire avec le pourcentage de chapitres lus
- Date d'achèvement estimée basée sur votre plan de lecture
- Série de lecture actuelle (si activée)
- Lien **Voir l'historique** vers l'historique complet de lecture

### Lecture du jour

Si vous avez un plan de lecture actif, une section surlignée affiche les chapitres assignés aujourd'hui. Chaque carte de chapitre comporte :
- Une case à cocher pour marquer comme lu (appuyer)
- Un bouton lien pour ouvrir sur JW.org

### Liste des livres et grille des chapitres

La colonne de gauche liste tous les livres de la Bible avec leur pourcentage d'achèvement. Appuyez sur un livre pour ouvrir sa grille de chapitres :
- **Bleu avec coche** — chapitre lu
- **Contour vert** — chapitre du jour
- **Gris** — non lu

### Plans de lecture

Modes de lecture disponibles :
- **Séquentiel** — Genèse à Apocalypse
- **NT → AT** — Nouveau Testament d'abord, puis Ancien Testament
- **Personnalisé** — glissez les livres dans votre ordre préféré
- **Mode libre** — pas de planning quotidien

Durées disponibles : 1 an, 2 ans, 3 ans ou nombre de chapitres personnalisé par jour.

En cas de retard, l'application replanifie automatiquement les chapitres manqués sur les jours suivants.

### Série de lecture

*Disponible à partir d'iOS 1.2.0 · Android 1.0.0*

Le compteur de série suit les jours consécutifs pendant lesquels au moins un chapitre a été lu :
- **Période de grâce de 2 jours** — la série reste active deux jours supplémentaires en cas de jour manqué
- **Célébrations de jalons** avec confettis et retour haptique après : 5, 14, 30, 90, 180 et 365 jours
- Célébration spéciale en plein écran à l'achèvement des 1 189 chapitres

### Historique de lecture

*Disponible à partir d'iOS 1.2.0 · Android 1.0.0*

Appuyez sur **Voir l'historique** dans la carte de progression :
- **Achèvements de la Bible** — journal de chaque date où vous avez terminé tous les 1 189 chapitres
- **Journal de lecture quotidien** — tous les chapitres lus, groupés par date

### Quiz de lecture

*Disponible à partir d'iOS 1.3.0 · Android 1.0.0*

Après avoir marqué les chapitres du jour comme lus, un bouton **Quiz** apparaît dans la section Lecture du jour. Le quiz teste votre compréhension des chapitres que vous venez de lire.

- Les questions sont tirées des chapitres lus aujourd'hui
- Fonctionne dans tous les modes de lecture, y compris le mode libre
- Appuyez sur **Démarrer le quiz** pour commencer ; glissez ou appuyez pour passer entre les questions
- Chaque question affiche la référence du chapitre biblique dont elle est tirée
- Votre score est affiché à la fin de la session

Le quiz est facultatif — vous pouvez le passer à tout moment.

**Replay du quiz par appui long** *(iOS 1.6.0 · Android 1.0.0)*
Appuyez longuement sur un chapitre lu dans la grille des chapitres pour le quizzer directement — sans avoir à terminer le plan de lecture du jour. Chaque chapitre peut rapporter des points une fois par cycle du programme de lecture. Si un chapitre a déjà été quizzé dans ce cycle, le même appui long lance une session de replay : votre score est affiché, mais aucun point n'est attribué. Lorsque vous terminez le programme complet (les 1 189 chapitres), tous les chapitres se débloquent pour un nouveau cycle.

### Suivi du Mémorial

Pendant la saison du Mémorial (environ une semaine avant et après le 14 Nisan), une carte du Mémorial et une section de lecture quotidienne apparaissent. Elles affichent les passages assignés de la Bible et les chapitres du livre *Jésus — le chemin, la vérité, la vie*.

## Paramètres

### Paramètres généraux

- **Nom** — votre nom, utilisé dans le rapport PDF de l'année de service et dans le message de partage mensuel. Synchronisé via iCloud si la synchronisation iCloud est activée.
- **Langue** — anglais, allemand ou français
- **Retour haptique** — activer/désactiver la vibration
- **Synchronisation iCloud** *(iPhone & iPad)* — synchronisation automatique optionnelle via l'identifiant Apple (désactivée par défaut)
- **Icône de l'application** *(iPhone & iPad)* — par défaut, vert, or, violet ou rouge
- **Côté du rail de navigation** *(tablettes Android)* — rail de navigation à gauche ou à droite en mode paysage
- **Export & Import** *(Android)* — voir [Export & Import](#export--import) ci-dessous

### Paramètres de rapport

- **Format de date** — avec aperçu en direct
- **Rôle récurrent** — rôle de ministère et objectif mensuel d'heures
- **Mission ponctuelle** — mois de pionnier temporaire
- **Historique des rôles** — entrées de rôles passées
- **Étudiants de la Bible** — ajouter, renommer, archiver ou supprimer des étudiants
- **Rappel NW Publisher** — affiche la bannière pour envoyer le rapport du mois précédent pendant les 10 premiers jours du mois (activé par défaut)

### Paramètres de lecture biblique

- **Langue de la Bible** — langue pour les liens JW.org
- **Mode de lecture** — séquentiel, NT→AT, personnalisé ou libre
- **Durée de lecture** — 1, 2, 3 ans ou personnalisé
- **Créer le plan / Recalculer**
- **Rappel quotidien** — notification push avec les chapitres non lus du jour
- **Série de lecture** — activer/désactiver le suivi de série
- **Difficulté du quiz** — filtrer les questions par niveau : Mixte (tous niveaux), Facile, Moyen ou Difficile
- **Nombre max. de questions** — définir le nombre maximum de questions par session (1–10)

### Paramètres du Suivi du Mémorial

- **Activer le Suivi du Mémorial**
- **Toujours afficher** — en dehors de la saison
- **Rappel du Mémorial** — notification quotidienne pendant la saison

### Export & Import

Sous Android, l'Export & Import se trouve dans **Paramètres → Général**.

- Exporte toutes les données en fichier JSON, à enregistrer où vous voulez (iCloud Drive, Fichiers, Google Drive, e-mail, etc.)
- Choisissez ce qui est inclus : Rapports de ministère, Lecture biblique, Lecture du Mémorial
- L'import restaure toutes les données sélectionnées
- Le format de fichier est identique sur iPhone, iPad et Android : vous pouvez transférer vos données d'une plateforme à l'autre

## Confidentialité & Données

- **Vos données restent privées** — rien n'est envoyé à des serveurs ou à des tiers ; aucun suivi ni analyse
- **Aucun compte requis** — l'application fonctionne entièrement hors ligne
- **Synchronisation iCloud optionnelle** *(iPhone & iPad)* — activez dans les réglages pour synchroniser vos données automatiquement sur tous vos appareils avec le même identifiant Apple ; désactivée par défaut
- **Sauvegarde Android** — l'application Android n'a pas de synchronisation intégrée ; si la sauvegarde Google est activée dans les paramètres Android, Android peut inclure les données de l'application dans la sauvegarde de l'appareil
- **Export/Import** — sauvegardez et restaurez vos données manuellement sous forme de fichier JSON
